FOUR COMMANDS.
ONE MAC.

On a supported Apple Silicon Mac, the project provides scripts to check your environment and prepare a local desktop build.

BEFORE YOU START
  • Apple Silicon Mac, macOS 26 or newer
  • Git and Go 1.27.2
  • Python 3 and Xcode Command Line Tools
Read the repository build notes ↗
TERMINAL · MACOS
git clone https://github.com/jenksed/yourmove-go.git
cd yourmove-go
./release/macos/doctor.sh
./release/macos/prepare.sh
WHAT HAPPENS NEXT

The prepare script tests and packages a locally built YourMove.app and related artifacts under ~/Projects/yourmove-builds. It does not install, notarize, or publish the app.

This is a development build signed ad hoc, not a notarized public installer. macOS may restrict opening it. Follow the repository's current instructions and only run code you trust.

BEFORE YOU
JUMP IN.

Is this a one-click installation?+

Not currently. Official public releases will be listed on GitHub Releases when they're published. The repository's source build requires development tools.

Does it work on Windows or Linux?+

Neither platform is qualified for public use yet. The documented desktop target is Apple Silicon macOS 26 or newer.

Will YourMove send applications for me?+

No. It assists with supported form fields; you review the employer form and decide when to submit.

Where do I ask for help?+

See the setup guide first. For bugs and project feedback, open an issue on GitHub. Don't include private résumé details, application answers, or passwords in public issues.
