Current source-build requirements

Desktop target
Apple Silicon Mac · macOS 26 or newer
Build tools
Git, Go 1.27.2, Python 3, and Xcode Command Line Tools
Employer-form assistance
Compatible installed Chrome/Chromium. Support varies by page and control.
Other environments
Intel and older macOS are not qualified. Windows and Linux are not qualified for public use; native desktop support is not implemented.
Build the Mac application

These are the official repository’s candidate-build commands. Check the current build notes before running them.

Terminal · macOS
git clone https://github.com/jenksed/yourmove-go.git
cd yourmove-go
./release/macos/doctor.sh
./release/macos/prepare.sh

The prepare script tests and packages a local YourMove.app, application and source ZIPs, and checksums under ~/Projects/yourmove-builds. It does not install, notarize, or publish the app.

This development build is signed ad hoc. It is not a notarized public installer, and macOS may restrict opening it. Follow the repository’s current instructions.

Run the local browser interface

With Git and Go 1.27.2 installed on a tested Apple Silicon Mac:

Terminal · local interface
git clone https://github.com/jenksed/yourmove-go.git
cd yourmove-go
go run .

Open http://127.0.0.1:3000 on the same computer. This is a local application, not a hosted account. Basic organization does not require Chrome/Chromium; assisted employer-form operations do.

A few practical things.

Will YourMove submit applications for me?

No. You review and submit on the employer’s website, then record completion in YourMove.

Where does my information go?

Your records and imported documents are stored on your computer. Retrieving postings, authorizing employer transfer, and using an external AI provider are separate network actions. Selected information may leave your device when you authorize those actions.

Where can I get help?

Start with Troubleshooting. You can also report an issue on GitHub. Issues are public: leave out résumés, application answers, passwords, and other private information.
