YourMove Is Here: A Free Mac App for Managing Resumes and Job Applications

Manage multiple resumes, organize job opportunities, reuse answers, and stay in control of your applications. Meet the first free YourMove Mac release.

By Joshua JenksNovember 5, 2026

More than one resume? More than one application?

If you’re applying for different kinds of jobs, you probably have different versions of your résumé. One emphasizes technical support. Another highlights project work. Maybe a third is tailored to customer success or operations.

Then there are the job postings you’ve saved, the answers you’ve already written, the cover letters, and the nagging question: Which résumé did I use for that application?

Keeping track of it all shouldn’t require another complicated system.

Today I’m releasing YourMove v0.1.0, the first public Mac version of a free, open-source application I’ve been building to make that work easier.

It’s a technical alpha, not a finished product. But it already does something useful: it helps you keep your opportunities, résumés, and application work in one place, then reuse what you’ve prepared instead of starting over every time.

Multiple resumes. Multiple opportunities. One place to work.

Different jobs call for different versions of your experience. That’s normal.

YourMove lets you import PDF and DOCX résumés, keep track of specific versions, and associate them with the opportunities you’re pursuing. You can save job details, work on applications over time, and return without rebuilding everything from memory.

That sounds straightforward. It should be.

The aim isn’t to generate dozens of vaguely tailored résumés or bury you in dashboards. It’s to make it easier to answer practical questions: What am I applying for? Which document belongs with this opportunity? What have I already prepared?

The next application should be easier than the last

A résumé is only part of an application.

There are cover letters, questions about your experience, and explanations you’ve probably written more than once. YourMove lets you save application answers and writing so they can be reused and adapted when they’re relevant.

It also includes Career Evidence, a place for applicant-reviewed descriptions of work you’ve actually done. You can preserve useful examples instead of trying to reconstruct a good story every time an employer asks about a challenge, accomplishment, or difficult situation.

And on supported employer application forms, YourMove can assist with transferring selected information and documents after you authorize it.

You still review the form. You still make the corrections. You still click Submit.

YourMove does not automatically submit applications on your behalf, and filling a form is not treated as proof that an employer received an application.

Why build another job-search tool?

There are already job trackers and application autofill tools. Some are more established and have more features than YourMove does today.

I’m not asking anyone to abandon a system that’s working for them.

What I want to offer is a free, local-first workspace built around the things applicants actually carry from one opportunity to the next: their documents, their answers, their experiences, and their own decisions.

Core records live on your Mac. YourMove is open source under GPL-3.0-only, so you can inspect the code. Optional AI-assisted writing is available if you choose to configure a provider, but it isn’t required for the basic workflow. External AI services may have their own costs and data-handling terms.

Local-first doesn’t mean the app never communicates with outside services. Looking up postings, interacting with employer websites, and using optional AI assistance can involve external connections. Those boundaries matter, and I want them to be clear.

I don’t think the goal should be to fire as many applications into the world as software can manage. I’d rather help people make better use of the time they’ve already invested.

What you should know before downloading

This first release is free, but early.

YourMove v0.1.0 is available for Apple Silicon Macs running macOS 26 or later. It is an unnotarized technical alpha, so installation requires the documented macOS security approval steps. Please use the installation guide and download only from the official GitHub release.

There are no automatic updates yet. Windows, Linux, Intel Macs, and older macOS versions aren’t supported by this release.

The assisted form workflow has been tested in controlled browser environments, but it won’t work with every employer website. Some forms will need to be completed manually. There may be bugs, confusing screens, or places where the workflow simply isn’t ready.

I don’t want anyone to mistake an alpha for software that has already been proven across every possible application.

If you’re comfortable testing an early Mac app, though, there’s a real product here to explore.

Help make the next release better

The most valuable feedback right now isn’t a download number. It’s learning whether YourMove makes an actual application easier.

Try adding a few opportunities. Import different résumé versions. See how it feels to prepare answers and associate your materials with the jobs you’re considering.

If something is confusing, tell me. If something fails, report it. And if there’s one part of applying for work that still feels unnecessarily repetitive, I’d like to hear about that too.

You don’t need to share your private documents to help. Use sample materials when testing, and please remove personal information, credentials, and sensitive employer details from any public report.

I’ll use that feedback to prioritize what needs fixing and what deserves to come next.

Less repetition. More of what matters.

Get started

Download YourMove v0.1.0 for Mac

Read the installation instructions first. For this release, technically comfortable testers are the right audience.

Found a problem? Report a bug. Have a suggestion or want to describe your experience? Share feedback.

You can also explore the open-source project or learn more about how YourMove works.

Your experience matters. Your time matters. Your next move should belong to you.
