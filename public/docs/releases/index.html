YOURMOVE v0.2.0

A more complete application workspace.

v0.2.0 brings more of the opportunity, résumé, question preparation, saved writing and employer-form workflow together in the native desktop experience. Keep preparation from one application useful for the next without giving up control of submission.

Download v0.2.0 for Mac ↗

Official GitHub release and technical notes · Mac installation guide

IMPROVEMENTS

Work you can carry forward.

  • Integrated preparation: More of the opportunity, résumé, questions, writing, browser and applicant completion flow is accessible within the native desktop workspace.
  • Improved job intake: Better posting recognition and metadata retrieval, including Ashby and Workday corrections, plus bounded initial checks for newly bulk-imported opportunities.
  • ATS source identification: Clearer platform indicators and fallback icons without implying that recognized platforms are all supported for Fill.
  • Questions and Answer Library: Work from observed employer questions, add questions manually, save reusable answers and review prior writing related to similar questions.
  • Multiple résumé versions: Import PDF or DOCX résumés and associate the right version with each opportunity.
  • Browser assistance: Better question observation, explicit Fill authorization and manual fallbacks where supported fields cannot be filled.
  • Native usability: Refinements to Opportunities, Job Workspace, local saving, persistence and recovery.

This list describes improvements consolidated in v0.2.0. Some capabilities were partially available in v0.1.0.

REQUIREMENTS AND LIMITS

What is actually supported.

Platforms: Apple Silicon (arm64) Macs running macOS 26 or later. Intel Macs, older macOS, Windows and Linux are not qualified for this release. Chrome/Chromium is needed for assisted employer-form operations, but not local organizing.

Security and privacy: The build is ad-hoc signed, not Apple-notarized. macOS may require per-app approval. YourMove stores job, document and writing records locally; accessing employer pages or using optional configured AI services can involve network requests and sharing selected information.

Applicant authority: YourMove never automatically submits applications. You review prepared writing, approve supported filling, handle unsupported fields manually, submit at the employer site and record the outcome separately. A successful Fill is not proof of submission.

Release testing covered selected workflows. A recognized ATS source does not guarantee that its forms can be filled.

INSTALL AND UPGRADE

Preserve your workspace.

New users can download the versioned DMG, drag YourMove into Applications and follow macOS installation and per-app approval instructions.

To upgrade from v0.1.0, quit YourMove first. Back up the entire ~/Library/Application Support/YourMove directory, including jobs.db, SQLite sidecars and resumes/. Replace the application, then reopen the same workspace. Keep the backup's database and résumé directory together.

Updates are manual in v0.2.0. See the complete upgrade instructions.
