YOURMOVE v0.3.0

Less hunting. Less guessing. More control.

v0.3.0 makes application work easier to navigate, return to, and complete deliberately. It refines existing preparation, writing and applicant-controlled submission workflows rather than introducing autonomous application submission.

Download v0.3.0 for Mac (.zip) ↗

Official SHA-256 checksum file · Canonical GitHub release · Full installation guide

WHAT IMPROVED

Make the work worth returning to.

  • Opportunities: Separate Focus, Saved for Later and History, review more compact opportunity rows, and see mixed import outcomes with retries for failed entries.
  • Questions and previous writing: Work in an editor-first workspace, consult earlier writing alongside the active draft, save your answers and receive a warning before leaving unsaved changes.
  • Posting availability and history: Distinguish confirmed closure from uncertain availability without erasing saved materials or previously recorded completion.
  • Apply and manual handoff: Clearer status and next-step guidance, including when a cover letter needs manual attachment on the employer’s site.
  • Separate Fill authorization: Review and authorize candidate-profile fields independently from saved-answer fields. Targeted recognition of certain Greenhouse LinkedIn and website/profile fields.

Local résumé management, saved writing, approved answer reuse and user-owned submission were already part of YourMove. v0.3.0 improves the experience of using these capabilities; it does not claim they were newly created.

REQUIREMENTS AND LIMITS

What is actually supported.

Platforms: Apple Silicon (arm64) Macs on macOS 26.0+. Intel Macs, older macOS, Windows and Linux are not supported by this build.

Employer forms: Ashby, Greenhouse and Lever have managed Capture and eligible Fill paths with controlled-test coverage. Coverage is conditional per form and control; an installed compatible Chrome/Chromium browser is required for assisted operations.

Manual controls: Custom dropdowns, sensitive disclosures, login, CAPTCHA, cross-origin embeds, manual attachments and unsupported or ambiguous fields can require direct completion. Always inspect the employer-side result.

Authority: YourMove does not automatically submit an employer application, and a filled form is not evidence of receipt. The applicant reviews, personally submits and records completion afterward.

Local-first data: Saved jobs, résumés, writing and application records remain in the local workspace. Posting retrieval, employer interaction and optional configured AI can use networks and transfer selected information with your authorization.

Distribution: This is an ad-hoc-signed ZIP, not a notarized DMG. Gatekeeper may require a specific per-app approval after verifying the source and checksum.

INSTALL AND UPGRADE

Verify the download. Preserve your workspace.

Download the official v0.3.0 ZIP and run shasum -a 256 "YourMove-0.3.0-macOS-arm64-unnotarized.zip" in the file’s directory.

Expected ZIP SHA-256:
b270101ca81f33a19f7829951c0061976ff73ad2cdcaa35854b43b1467b5c365. Stop if it differs. Compare with the published checksum file.

Before upgrading, quit YourMove and back up the entire configured workspace (normally ~/Library/Application Support/YourMove, including jobs.db, sidecars and resumes/). Double-click the ZIP in Finder, move the extracted YourMove.app to Applications and replace only the older app bundle. Retain the workspace and backup; verify saved records after first launch.

If blocked as unnotarized, use macOS per-app approval instructions. Never disable Gatekeeper globally; stop on damaged-app or malware warnings.

v0.3.0 requires a manual upgrade. The stable in-app channel still advertises v0.2.0, so “You are up to date” does not mean v0.3.0 is installed.
