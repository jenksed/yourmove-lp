Documentation/Install on Mac
BEFORE YOU INSTALL

Install YourMove
on your Mac.

YourMove v0.1.0 is an early Mac alpha for Apple Silicon. It is ad-hoc signed and not notarized, so macOS will ask you to approve it once. That approval is your choice, for this app only.

What you need

An Apple Silicon Mac (M1 or newer) running macOS 26 or later. Intel Macs, older macOS, Windows, and Linux are not supported in this release. An installed Chrome or Chromium browser is only needed for assisted employer-form filling; local organization works without it.

STEP 1 · DOWNLOAD

Get the installer disk image.

Download YourMove-0.1.0-macOS-arm64.dmg from the official v0.1.0 release. Afterwards, confirm the download is intact:

shasum -a 256 YourMove-0.1.0-macOS-arm64.dmg

Compare the result with the published checksum d84e…acee4d3 (full value in SHA256SUMS). A ZIP of the same app is listed beside it as an alternative.

Download the v0.1.0 DMG ↗
STEP 2 · INSTALL

Drag it into Applications.

Open the DMG. Drag YourMove onto the Applications folder, then eject the disk image. The installer window also carries two helpers: an Installation Guide shortcut back to this page, and an Open Privacy & Security shortcut for the approval step below.

STEP 3 · FIRST LAUNCH

Expect one macOS warning.

Open YourMove from Applications. Because this alpha is not notarized, macOS shows a “YourMove” Not Opened warning saying Apple could not verify the app. This is expected. Choose Done — do not choose Move to Trash.

STEP 4 · APPROVE

Approve it once, for this app only.

Open System Settings → Privacy & Security (the installer shortcut opens that exact pane; your browser may first ask permission to open Settings — choose Allow). In the Security section, select Open Anyway for YourMove, then open the app again and confirm. This exception covers YourMove only. It does not change your global security settings, and nothing here disables Gatekeeper.

IF SOMETHING LOOKS WRONG

No approval button?

The Open Anyway control appears only after a blocked launch attempt. Open YourMove from Applications first, choose Done on the warning, then check Privacy & Security again. If the button still does not appear, confirm you are on macOS 26+, then re-download the DMG (a damaged download can fail differently) and retry. Never turn Gatekeeper off or strip security metadata to get past this.

PREFER THE ZIP?

The ZIP holds the same app.

YourMove-0.1.0-macOS-arm64-unnotarized.zip contains the identical accepted build 3. Extract it, move YourMove to Applications, and follow steps 3–4 above.
