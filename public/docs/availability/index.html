Documentation/Install on Mac
v0.2.0 · TECHNICAL ALPHA

Install YourMove
on your Mac.

YourMove v0.2.0 was released November 13, 2026. It is free to download, ad-hoc signed and not Apple-notarized. macOS may require approval for this specific app.

Supported release: Apple Silicon · macOS 26 or later

Intel Macs, older macOS versions, Windows and Linux are not qualified for this release. Compatible installed Chrome/Chromium is needed for assisted employer-form filling, not for local job or document organization. Optional AI features may require separately configured provider credentials.

01 / DOWNLOAD

Get the official v0.2.0 DMG.

Download YourMove-0.2.0-macOS-arm64.dmg from the official GitHub release. This technical-alpha installer is about 9.1 MB. Verify its integrity with:

shasum -a 256 YourMove-0.2.0-macOS-arm64.dmg

Expected SHA-256:
11457b1cf4bed25e15c23c1d544eacad5eac21141efd44dbefbbf78e2d046b65

Compare the result with the published DMG checksum or the combined checksums. If the values differ, do not open the file.

Download v0.2.0 DMG ↗
02 / INSTALL

Move YourMove into Applications.

Open the DMG, drag YourMove.app into Applications, then eject the disk image. This build is not Apple-notarized; approval may be required at first launch.

03 / FIRST LAUNCH

Use macOS's per-app approval.

Open YourMove from Applications. If macOS blocks it, choose Done. Open System Settings → Privacy & Security and, if offered for YourMove, select Open Anyway. Open the application again. This approves only this app, rather than disabling Gatekeeper.

IF APPROVAL IS MISSING

Don't bypass system protections.

Attempt the launch from Applications first. If macOS still does not offer approval, capture the exact error and report it. Do not disable Gatekeeper globally or remove quarantine attributes.

UPGRADING FROM v0.1.0

Back up the whole workspace.

Quit YourMove completely. Copy the entire ~/Library/Application Support/YourMove folder to a safe location. Include jobs.db, any SQLite sidecar files, and the resumes/ directory together. Never combine a database backup with résumé files from a different workspace.

Then install v0.2.0 over the older application and reopen the same workspace. Migration testing covered selected data, not every possible configuration. Updates are manual in v0.2.0; there is no promised in-app updater.

OTHER RELEASE FILES

Need the ZIP or source?

The unnotarized Mac arm64 ZIP is another app archive for this release. Extract it, move YourMove into Applications, and follow the same macOS approval instructions.

The v0.2.0 source ZIP requires build tools and is not an installer. For new features and limitations, read the v0.2.0 release notes.
